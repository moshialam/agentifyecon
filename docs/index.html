LLMs for Economists

Example-based guidance for agentic coding with Claude Code.

A field guide for colleagues to one specific way of using LLMs: giving an AI agent direct access to your project files so it can write code, edit your LaTeX, audit a replication package, and run things on your behalf — under your supervision.

This is not about chatting with ChatGPT in a browser. That is useful too, but it isn’t what changed in the last year.

Suggested reading order

If you have 30 minutes, read:

  1. Principles — the three things that determine how useful Claude Code will be for you.
  2. What is agentic coding?
  3. Install Claude Code, then use it inside VS Code — strongly recommended if you’re coming from RStudio, Stata, or Matlab. (If you’ve never used the terminal, the five-minute terminal primer is helpful background even if you go the VS Code route.)
  4. LaTeX paper editing or Replication package audit.

If you have a free afternoon, add:

  1. Plan mode, todos, slash commands
  2. The example page for your language: Stata, R, or Julia.
  3. How to ask and Verifying output.
